# CMPSC132 - Final Project

Project Description

The Number Guessing Game is a terminal-based Python program where the computer randomly generates a number within a selected range, and the player attempts to guess it. After each guess, the program provides feedback indicating whether the guess is too high or too low. The game continues until the correct number is guessed, while tracking the number of attempts. The program also includes difficulty levels and a replay option to enhance the user experience.

Game Instructions

1. Run the program.
2. Choose a difficulty level:
 - Easy (1–10)
 - Medium (1–50)
 - Hard (1–100)
3. The computer will generate a random number within the selected range.
4. Enter your guess when prompted.
5. The program will respond with:
 - “Too high” → guess a lower number
 - “Too low” → guess a higher number
6. Continue guessing until you find the correct number.
7. The program will display how many attempts it took.
8. Choose whether you want to play again.
